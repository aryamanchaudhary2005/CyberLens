## Known scope and limitations

- Demo mode intentionally uses synthetic fixtures and makes no external requests. Live provider checks require public network access; VirusTotal and HIBP email-breach lookup require suitable keys/entitlements, while HIBP password screening uses the keyless range API. - Only existing VirusTotal URL reports are queried; URL query strings and fragments are removed. HIBP is limited to an explicitly registered email and does not enumerate a domain.
- NVD results are analyst-reviewed candidates. Only findings marked applicable contribute to vulnerability risk; KEV prioritization requires analyst-confirmed applicability.
- Website/TLS observations are bounded and are not a full cipher/protocol audit. The score is an academic prioritization aid, not a probability of compromise or validated industry metric.
- The project targets one local shared workspace. Multi-tenant isolation, public deployment hardening, uploads, automatic containment, external notifications, and SIEM integration are outside the implemented scope.
- The default local gateway uses a locally generated Caddy certificate; it is not a publicly trusted certificate. Local Live is not public-production ready. Existing Demo records are preserved in storage and are hidden from normal Live workspace views; the Demo project is separate from the default Live project.
